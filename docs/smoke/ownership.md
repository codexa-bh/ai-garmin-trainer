## Ordinary-artifact isolated scenario

Use a current unmodified `desktop:build` ordinary bundle and [authored inputs](../smoke-inputs.md). Scratch must already be canonical, owned and 0700; never chmod/adopt insecure input. Optional private database-only 0600/single-link selection needs current grant/provenance verification before consumption. Missing/revoked/expired/mismatched authority refuses without fallback. Never discover normal settings/env/keys/tokens; the workspace private-fixture inventory owns grants/retention.

The runner online-backs up input into exclusive roots, inventory-verifies bundle copies **outside checkout**, and launches only owned children with `--isolated-smoke-run <launch.json>`. No binary/plist/resource patching. Capability stays in private config/memory/headers, never argv/env/URLs/logs. `--prepare-only` launches nothing and proves no smoke success.

### Admission, state and lifecycle

Native verifies descriptor/source/build/resource/artifact identity before framework state/windows, pins private paths and holds lifetime/DB leases. Existing run-local settings are normally required; only explicit [history setup](sync.md#bounded-ordinary-history-setup-and-copied-token-sync) admits absent settings/Create-new DB. Newest run-config takes precedence; invalid newest state never falls back. Manual Save retains catalog/revision validation and DB confinement.

All writable config/app-data/WebView/temp/DB state is run-local; ordinary **HOME stays unchanged**. No normal credential import/readback or sign-in automation. An authored Garmin key requires the owned loopback fixture; real service requires separately authorized native input. Invalid intent exits nonzero, never normal singleton fallback. Replaced/aliased paths, same-root owners and stale boots/capabilities refuse. Restart requires reaping/endpoints/leases settled, fresh namespace lease/descriptor capability and native boot.

Default launch remains the normal focus-taking singleton with no bootstrap/controller/result grant; second-instance arguments cannot retarget it. Do not launch against operator state to certify routing.

Choose images before launch with repeated `--capture 'group:state:view:preset:instance=visual reason'` and `--image-basis '<selected and omitted visual scope>'`. Ordinary `--plan-only` prints finite opportunities and omissions without input access/allocation/launch (required scratch/bundle arguments are not accessed). Unknown, duplicate, impossible or malformed requests refuse before preparation; requested-but-unexercised images fail the aggregate. For example, a composer change can select `composer:saved:composer:narrow:1=Changed saved long-label footer at narrow width` while retaining full behavior and omitting unrelated baseline pictures. Nonvisual work leaves the selection empty and records `Screenshot: not applicable — <behavioral reason>` with actual assertions. Empty selection or a masked/unrelated image cannot satisfy missing changed-state visual proof.

Selected Trainer/Sync/Profile images use 1280×850 and 420×850 logical viewports. Masks default hidden and reveal only reviewed static controls and run-authored values at real geometry; never reposition/reflow Profile. Unknown structure refuses; unreviewed descendants remain hidden. Masks restore on success/error/expiry. Inspect **every relied-on original PNG**; hashes/booleans/contact sheets do not replace visual review. Hidden regions are intentional, not full-window/trusted-input proof. macOS PNGs stay temporary/local, never committed/uploaded. Focus sampling is 10ms, with no activation/restoration; disclose if no operator app was live.

Only live child handles authorize shutdown. Verify reaping, endpoints and DB/run leases. Preserve originals, never copy back. Scenario success and resource disposition are independent.

Saved stronger obligations still bind. Summary cannot combine with composer/conversation; lifecycle rejects presentation-family selection. Every scope retains identity/admission/preservation/noninterference/settlement infrastructure; only exercises may be omitted. Presentation fixtures prove no inference, persistence or compositor-frame progression; [scenario owners](ordinary.md) state limits.

The image-selection contract above applies to ordinary composer/eligibility/conversation/Memory and declared composition opportunities, including Snow/native geometry. Explicit legacy Snow `--compact-captures` remains a named gallery and cannot combine with targeted requests. Unchanged direct table/chat/Terrain/weekly/About runners retain their documented gallery recipes; invoking one is not a requirement to photograph it for an unrelated task. Bind relied-on originals to source/artifact/run/state/time/hash and visual analysis. No second copied-original review tree; contact sheets are derived aids. Existing category archival/retention remains. Count actual logical/allocated bytes separately; APFS allocated blocks are not proven reclaimable savings. Missing private/provider/installed/trusted-input proof is unavailable, not passed.

## Ordinary build identity and current-driver reuse

`desktop:build` always requests full Next/resources/unsigned ARM64 packaging under preparation lock, producing ordinary-only v2 inventory identity. Assembly/debug/probe/legacy stamps do not qualify; rebuild unsupported provenance rather than rewriting it.

Original `sourceFingerprint` binds whole-source/Git/dirty state. Classifier-v1 `buildSourceFingerprint` exempts only tracked exact `ordinary_smoke.py`, `ordinary_smoke_test.py` and `docs/dev-bridge.md` external drivers. All other tracked/nonignored untracked, renamed/deleted, packaged/preparer/bootstrap/build/classifier inputs affect builds; no glob exemption. Modes/deletions are bound. `buildContext` binds worktree/lock identity, installed dependencies, locked inputs, platform/tools/SDK/environment; native identity always names the original build snapshot.

Only `smoke:ordinary` supports corrected external-driver reuse. Hold lock through copy/checks at every boot/execution/final preservation. Changed/ambiguous stamp/context/inventory refuses without auto-build. A hit still runs the current scenario; new oracle failure is failure. Reuse/ordinary receipts bind current driver/options, input hashes/provenance, original artifact and outcome. Other/paid callers retain stricter exact-source rules unless separately qualified. Reuse grants no settings/auth/service/default-window authority; measure actual times, not counters alone.

## Preparation reuse and owned disposal

Managed scratch delegates evidence/disposable categories to the harness for the exact task root; foreign/incompatible results refuse. Bulk DB/settings/WebView/runtime/bundle copies are disposable; compact logs/receipts/provenance/native PNGs are evidence. The invocation owner archives evidence before disposal; there is no parallel disposer. Standalone published preparation, borrowed inputs and prepare-only runs retain their promised outputs; borrowing grants no deletion.

Checkout-local `.next`, `dist`, `src-tauri/resources`, `src-tauri/target`, `node_modules` remain exact toolchain exceptions, isolated per worktree. Never share mutable output. Reuse requires preparation lock and exact source/dependencies/environment/toolchain/mode/resources/executable identity; bad identity rebuilds or refuses, and explicit `--resources-ready` mismatch always refuses. Swift observer reuse binds source/compiler/SDK. Debug/probe stamps remain separate; no existence-only cache hit or substitute for final smoke.

Immediate disposal covers only new exclusive allocations in the live ledger after scenario/restart/denial/inventory, reaping/endpoints/leases, input preservation and final receipt. Intermediate stop retains restart inputs. No-follow descriptor-relative identity/inventory checks and quarantine/reverification reject replaced parents, links/hardlinks, foreign contents, unknown sidecars or unsettled leases. Only verified readonly probe-copy directories may become writable, never originals.

Disposition receipts record exact removed/retained paths/counts/bytes separately from scenario success. PNGs/logs/compact evidence survive; dynamic WebView/home/unenrolled sidecars are not recursively adopted. Failure/interruption/timeout/unknown/partial construction/preservation/shutdown/receipt failure preserves state and original error; cleanup failure remains nonzero. Managed disposable expiry is six hours after canonical closure, independently of outcome; no holds/reclassification/extension. Select non-reconstructable evidence before close, not whole apps/caches. No authority to sweep historical state, worktrees, aliases, private originals or accepted outputs.

## Evidence and recovery

Keep original failures beside repairs and record identity, actual scenario/restart/shutdown, image inspection, original integrity and focus limits. Sentinels stay in copies. Run focused native/controller/DOM/Python contracts before affected build/smoke; do not repeat unchanged heavy work while waiting for CI. Recurring CI uses synthetic quick smoke, not the full private/release suite.

Keyless navigation/Profile proves no provider/Garmin/native-dialog or untested-platform behavior. Missing safe task-needed controls follow [extension rules](protocol.md#task-needed-bridge-and-runner-extensions), not invented equivalence or a permanent feature ban.
