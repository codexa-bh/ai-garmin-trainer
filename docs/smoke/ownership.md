## Ordinary-artifact isolated scenario

`smoke:ordinary` consumes a current, unmodified `desktop:build` ordinary bundle. Input defaults to the [authored preparer](../smoke-inputs.md); no personal data/approval needed. Scratch is already canonical, owned, `0700`; never chmod/adopt insecure input. Optional private input is bounded `0600`, single-link JSON containing exactly `database`, with current `--grant-file`/`--provenance-file` rechecked before consumption. Applicable standing grants may survive tasks; missing/revoked/expired/mismatched authority refuses without fallback. Never discover normal settings/env/keys/tokens. Pivan's selected workspace `epics/E0007-ai-garmin-connect-trainer/content/private-smoke-fixture-inventory.md` owns private approval/retention; neither this document nor discovery supplies a grant.

The runner online-backs up input into two exclusive `ordinary-<UUID>` roots and inventory-verifies unmodified bundle copies outside checkout. No binary, Info.plist, identity or packaged resource replacement. Each owned child directly launches with `--isolated-smoke-run <root/launch.json>`; capability never appears in argv/env/URL/logs. `--prepare-only` retains independent preparation/provenance with zero launches, not smoke success.

- Default launch still uses normal settings/focus-taking singleton with **no** controller/bootstrap/result grant. Second-instance arguments cannot retarget it. Do not launch it against operator state merely to certify routing.

Only `smoke:ordinary` supports corrected external-driver reuse. It holds the worktree lock through verification/copying/current checks at **each boot**/fresh execution/final preservation. ## Production exclusion and required artifact evidence

After final validation/current unsigned ARM64 build, run the catalog's `release-audit` with a prepared database-only selection. It inventories the **actual ordinary bundle**, requires supported isolated admission/control markers and rejects precise legacy debug admission/grant/probe markers. Shared controller/callback code is intentionally present; presence does not mean enabled by default.

It then builds a separate `release-probe`: only run-local paths/identity/incognito/nonactivation and fixed denial observation, **no** listener/control/capture/result callback. A copied app with read-only resources receives enabling env yet exposes no endpoint and denies the fixed WebView request (`command-not-found` or earlier ACL refusal). Report actual reason, reap only live child, verify original inventory. The unbundled executable may now be instrumented; ordinary build never enables this feature and bundled app stays unchanged.

Static audit plus instrumented denial **is not ordinary-artifact launch**; use `smoke:ordinary`. Native routing tests are not a live default UI certificate. Manual private settings/auth requires a specifically arranged noninterfering operator window.
