Settings

Settings and provider keys are stored in an owner-private plaintext file on this Mac (folder 0700, file 0600), not encrypted. The same user, privileged processes and backups can read them. Saved keys are never displayed. Existing env files are not loaded or imported.

The selected database will be writable. Quit any other app or older backend using it first. For evaluation, select a disposable populated copy. Existing databases are never initialized or upgraded. First-run Create new is a separate, exclusive operation on an unused destination.
