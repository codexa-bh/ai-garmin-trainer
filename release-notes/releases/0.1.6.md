# AI Trainer for Garmin Connect 0.1.6

Status: prepared

Unsigned and not notarized; macOS may refuse to open this app.
Existing databases require the matching source CLI, a stopped owner and verified backups; startup never upgrades them.
Bundled notices are not redistribution authorization.

## macOS ARM64 only

This release includes only the unsigned, non-notarized macOS ARM64 DMG. Minimum macOS 12.0 is not minimum-OS certification. There is no Windows build in this release; [v0.1.4](https://github.com/eye1/ai-garmin-trainer/releases/tag/v0.1.4) remains the last Windows x64 alpha, with its original qualification limits.

## Before upgrading

No database schema change: 30 → 30. No database migration is needed from 0.1.5 or 0.1.4. Older databases still require the matching source CLI, a stopped owner and verified backups; startup never upgrades them. Keep the prior compatible app, database backup and settings together. The app shares data/settings with the formerly named Garmin Trainer: quit that app before opening this one. Installing is not a database upgrade or historical backfill.

## Changes

### Added

- Views and chat answers built from Garmin data now show a small Garmin source label; manually entered Profile fields and KPI targets stay unlabelled.

### Changed

- Give chat messages more space by removing the redundant chat heading.

- On Mac, Trainer initially fills the available screen height, then remembers your chosen window size and position and recovers onscreen when displays change.

- Trainer chat can batch independent reads and starts with current planning context to avoid redundant model round trips, while preserving guarded saves and clearer long-turn timing diagnostics.
