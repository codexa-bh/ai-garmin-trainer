# AI Trainer for Garmin Connect 0.1.5

Status: prepared

Unsigned and not notarized; macOS may refuse to open this app.
Existing databases require the matching source CLI, a stopped owner and verified backups; startup never upgrades them.
Bundled notices are not redistribution authorization.

## macOS ARM64 only

This release includes only the unsigned, non-notarized macOS ARM64 DMG. Minimum macOS 12.0 is not minimum-OS certification. There is no Windows build in this release; [v0.1.4](https://github.com/codexa-bh/ai-garmin-trainer/releases/tag/v0.1.4) remains the last Windows x64 alpha, with its original qualification limits.

## Before upgrading

No database schema change: 30 → 30. No database migration is needed from 0.1.4. Older databases still require the matching source CLI, a stopped owner and verified backups; startup never upgrades them. Keep the prior compatible app, database backup and settings together. The renamed app shares data/settings with Garmin Trainer: quit the old app before opening the new one. Installing is not a database upgrade or historical backfill.

## Changes

### Added

- Install or update on macOS with one Terminal command; see the README.
  - The command downloads the latest release, verifies its checksum and copies the app to Applications. Quit the app first.

### Changed

- Maintainers can check the actual public release body before source freeze or native builds with `npm run release -- preflight --preflight-context <context.json>`, checking signing, qualification and schema/recovery disclosures for the explicitly selected platforms.
  - Supply prior-release/current schema context. Preparation rechecks it before consuming fragments. This macOS-only cut has no current Windows qualification; the manual Windows job remains blocked by its frozen 0.1.4 preflight context until a future Windows cut.
  - Qualification reports phase/subphase timings and reduces repeated inventory overhead while still hashing current bytes; no verification is skipped. Windows installed lifecycle and exact-installer checks remain required for a future Windows cut. The separate fast-development path is documented only, not implemented.

- The app is now named AI Trainer for Garmin Connect (previously Garmin Trainer).
  - This release's macOS download, app and windows use the new name; your data and settings are unchanged. No Windows installer is included.
  - Installing does not replace an existing Garmin Trainer app. Both names share data and settings: quit the old app before opening the new one, and retain the prior compatible app and verified backups for recovery.

- The app's own code and assets are now licensed under Apache-2.0 instead of MIT.
  - Versions up to 0.1.4 remain available under MIT.

### Fixed

- Reconnect ChatGPT using the app's saved registration instead of creating another connected app; routine test builds cannot register real accounts.
  - Switch account now distinguishes saved connections from an explicitly new account/workspace. Interrupted attempts retain known issued registrations across restarts; unknown registration effects require reconciliation rather than a blind retry.
  - Existing duplicate entries are not removed automatically. Preserve the intended connection; identical names or list order do not identify obsolete entries.

- Trainer weekly KPI questions recover available saved targets when a requested version is unavailable, without asking you to manage internal IDs. Missing versions and empty weeks stay explicit, and read recovery never changes saved data.
